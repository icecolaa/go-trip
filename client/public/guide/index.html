GOTRIP USER GUIDE

🧭 出发吧 · 图文使用说明

和朋友一起，规划每一次出发 —— 5 分钟上手

🚀快速开始

  1. 注册 / 登录：打开应用 → 输入用户名密码注册（或用演示账号 demo / demo1234 体验）
  2. 创建旅程：仪表盘点「＋ 创建旅程」，填标题、目的地和日期
  3. 邀请朋友：进入旅程 → 「成员」页创建邀请码发给朋友，或直接输入对方旅行 ID 添加
  4. 开始规划：手动添加安排，或交给 AI 一键生成

登录 / 注册：支持演示账号一键体验

1每日行程：规划的起点

  • 「＋ 添加行程」：填时间、做什么、地点，可搜索定位（带坐标才能上地图）
  • 每站右侧「修改 / 删除」随时调整；按住左侧 ⋮⋮ 可拖拽排序、跨天移动
  • 「✨ AI 助手」：按目的地 + 天数 + 节奏生成整段行程，或粘贴攻略文本自动解析（一般 20~60 秒，请耐心等待）
  • 顶部 D1~Dn chips 快速切天；天气胶囊展示当日预报

每日行程：每站含时间、地点、费用与备注

2出发模式：旅途中的当天视图

行程页点「🧭 出发模式」，进入全屏当天视图——这是旅途中真正会打开的界面：

  • 顶部日期条切换当天，勾选完成一站，「下一站」自动橙色高亮
  • 手绘路线图展示各站方位（断网也能看）
  • 每站可跳「高德导航」与「小红书」看攻略
  • 底部「复制今日路线」一键转发给同伴；「高德导航全天路线」按行程顺序串起所有站点

出发模式：勾选进度 + 手绘路线 + 一键导航

3旅行地图：一眼看全行程

  • 全部已定位地点按 D1~Dn 分色展示，虚线为建议路线顺序
  • 顶部 D1~Dn chips 按天筛选查看
  • 「🗺️ 高德搜索全部目的地」：把所有站点按行程顺序串成高德路线，一键导航
  • 「📋 复制全部行程」：完整行程文本进剪贴板，方便分享
  • 「地点搜索」面板可搜任意地点并直接加入某天行程

旅行地图：分色标记 + 按天筛选 + 一键串联路线

4团队预算：记账与结算

  • 「＋ 记一笔」：填说明和金额，选垫付人；可指定只有部分人分摊
  • 自动统计「团队总花费 / 我垫付的 / 待收回」与分类占比
  • 结算方案自动算出「转账最少」的组合，照着转就两清

旅行钱包：统计、分类占比与结算方案

5打包清单：别落下充电宝

  • 「从模板导入」：证件 / 衣物 / 电子 / 洗护 / 药品等 6 套模板一键生成
  • 物品可指派负责人、写数量与备注；出发前逐项勾选

出发准备清单：按分类勾选、指派到人

6旅行锦囊：目的地攻略手册

  • 「✨ 按目的地重新生成」：AI 生成美食 / 贴士 / 语言 / 拍摄四类卡片
  • 内置全国 20+ 热门城市与出境目的地内容，未配置 AI 也能用
  • 「＋ 自定义卡片」记录团队约定、老饕私藏清单

旅行锦囊：美食、贴士、语言、拍摄四类手册卡

7成员与分享：把大家拉进来

  • 邀请好友：生成邀请码/链接（可限次数与有效期），朋友注册登录后自动加入
  • 旅行 ID 添加：对方在「我的」页查看自己的 6 位 ID
  • 只填名称占位：还没注册的家人朋友先占个位，之后自动绑定
  • 角色：发起人 / 管理员 / 成员 / 观察者，分级权限；发起人可转让
  • 对外分享：开启只读链接，适合发给长辈或不用操作的同行人

成员管理：角色、邀请、对外分享

🔗攻略收藏：小红书 / 公众号一键直达

刷到好攻略随手存进来，行程相关的参考内容不再散落在收藏夹：

  • ＋ 收藏链接：粘贴小红书笔记、公众号文章或任意网页链接
  • 按类型筛选（小红书 / 公众号 / 网页），点击标题直达原文
  • 团队共享：同旅程的伙伴都能看到与使用

攻略收藏：按类型归档，点击直达原文

8日志与动态：记录与回顾

  • 日志：带心情的旅行手记，可关联某一天；谁写的谁编辑
  • 🖼️ 图片：发布时可添加最多 9 张图片（自动压缩、生成缩略图，点击看大图）
  • 动态：全员操作自动生成时间线，谁改了行程、记了账一目了然

旅行日志：心情手记，按天关联

✨更多好用的小功能

  • 💬 使用助手：任意页面右下角悬浮球，随问随答使用问题；右上角 × 可隐藏，屏幕右缘小图标找回；按住可拖到顺手的位置
  • 🌙 夜间模式：顶栏一键切换，晚上看行程不刺眼
  • 手机适配：手机浏览器直接访问，布局自动适配

手机浏览器访问，自动适配小屏

夜间模式：顶栏一键切换，跟随主题配色

❓常见问题

  • 地图上有些站点没显示？——添加/编辑行程时在「地点」框搜索一次即可定位
  • AI 生成很慢？——正常需 20~60 秒（复杂行程更久），界面有进度提示
  • 忘了密码？——暂不支持自助找回，可重新注册（数据不互通）
  • 想删掉整个旅程？——发起人在「成员」页操作解散
  • 线上访问偶尔提示休眠？——免费托管闲置会休眠，点「唤醒并继续」等 10~30 秒即可；用前可运行 node scripts/keepalive.mjs 保活

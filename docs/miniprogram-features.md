# GoTrip 小程序功能清单 · UI 改版底稿

> 2026-09-27 提炼，基于 12 页代码逐页核对（非印象）。
> 用途：小程序 UI 改版的功能输入。改版只动「皮」（样式/布局/组件），以下功能事实与「改版硬约束」是必须保住的东西。

## 一、产品与页面地图

定位：给同行伙伴用的旅行规划工具——行程、预算、清单、锦囊、日志、低价机票，一个都不少。

```
trips(我的旅程/首页)
├─ flywhere（飞哪儿·低价机票，顶部横条入口）
├─ trip-create（新建旅程）
└─ trip(行程详情·核心页)
   ├─ activity(安排新增/编辑)
   ├─ budget(预算记账)
   ├─ packing(打包清单)
   ├─ journal(旅行日志)
   ├─ handbook(旅行锦囊)
   ├─ members(同行伙伴)
   ├─ map(行程地图)
   └─ trip-ai(AI 解析攻略)
```

无 tabBar（单入口层级流），原生导航栏（碳黑底白字），每页一个 `index.tsx + index.config.ts`，**样式全部集中在 `src/app.css`，无页面级样式文件**。

## 二、逐页功能与交互事实

### 1. trips 我的旅程（首页）
- 区块：飞哪儿入口横条 → 标题行(＋新建) → 错误条 → 空状态(导入演示行程按钮) → 旅程卡列表
- 旅程卡字段：封面 emoji、标题、目的地、N 项安排、已花 ¥、起止日期
- 交互：下拉刷新、每次 show 重载、点卡进行程、「＋新建」、空态一键导入演示行程

### 2. trip-create 新建旅程
- 纯表单：名称、目的地、双列日期 Picker、预算(选填)、封面 emoji 网格(14 选 1)、封面颜色圆点(6 色)
- 交互：开始日期变更自动顺延结束日期、选中态高亮、提交校验、成功 redirectTo 行程页

### 3. trip 行程详情（核心页，改版重点）
- Hero 卡：emoji+标题+目的地+日期、旅程进度条（绿金渐变）、预算/已花、**7 个功能 chip**（💰预算 🎒清单 ✍️日志 📖锦囊 👥成员 🗺️地图 AI解析）
- 天分组列表：D1/D2/Dn 黑底方块、天主题+日期·地点、每天「＋安排」；活动行=时间/分类 emoji/标题/地点/费用/备注
- 交互：下拉刷新、点活动行进编辑、天空态提示；**行程本体无编辑/删除入口**（Web 也没有，功能缺口）

### 4. activity 安排编辑（新增/编辑同页）
- 表单：内容*、时间+费用双列、分类 Picker(7 类 emoji)、地点、备注；编辑态多「删除」
- 交互：时间格式自动纠正（全角冒号）、删除二次确认

### 5. budget 预算记账
- 汇总面板：已花/预算 + 进度条（超 100% 变橙红）+ 分类金额列表
- 成员结算面板：每人 垫付/应付/多付·待付（正绿负橙红）
- 记账表单（展开式）：项目、金额、分类 Picker(7 类)、支付人 Picker
- 支出明细列表：点行删除（确认弹窗）；均摊逻辑固定 equal

### 6. packing 打包清单
- 进度面板（已打包 n/m + 进度条 + 「导入模板」）+ 快速添加行（输入+分类+添加）
- 6 固定分类分组（证件/衣物/电子/洗护/药品/其他），行=自绘勾选框+名称+数量+备注，勾完删除线
- 交互：**乐观更新**（先勾本地失败回滚）、6 套模板 ActionSheet 导入（按名去重）

### 7. journal 旅行日志
- 发布卡：3000 字文本、8 心情 emoji、＋图片(≤9 张)缩略图可删、发布
- 日志流：作者+心情+日期、正文、九宫格图
- 发布链路：压缩 75% → 云存储 fileID → tempUrls 临时链展示（禁止 base64 入库）

### 8. handbook 旅行锦囊
- 生成器：6 兴趣 chip 多选（美食/自然/人文/亲子/购物/夜生活）→「生成锦囊」（AI 20~60s loading）
- 卡片按 category 分组：icon+标题、摘要、label+text 条目列表；删除走确认
- 内置 20+ 城市兜底内容（未配 AI 也能用）

### 9. members 同行伙伴
- 占位成员管理（无需对方装 App）：彩底首字头像、发起人角色标、改名（可编辑 Modal）、移除（提示失去分摊关联）
- 底部：称呼输入 + 添加

### 10. map 行程地图
- 微信 `<Map>` 60vh：有坐标的活动打点，callout 显示 emoji+标题+费用；下方「有坐标的活动 N/M」列表（≤20 条）
- 无坐标时提示文案（坐标来自网页版地理编码）
- ⚠️ 现状 bug：`iconPath: '/assets/marker.png'` 引用的图**不存在**（src 下无 assets 目录）

### 11. trip-ai AI 解析攻略
- 粘贴攻略文本（6000 字，支持 Day N/第 N 天/D5 标头）→「解析预览」→ 逐天预览
- 写入：「只替换第 N 天」（识别天号在范围内才出现）或「覆盖全部行程」（红字）；写后自动补坐标
- ⚠️ 数据危险操作，「覆盖全部」无二次确认输入

### 12. flywhere 飞哪儿（体验最特殊的页）
- 表单：出发城市、目的地(空=全国)、往返日期、往返/单程分段控件、黑底搜索按钮
- 异步 job：提交秒回 jobId → 2.5s 轮询（120s 上限）→ 每秒跳动的「已等待 N 秒」
- 结果卡：城市、总价、去/回程航段、时长、航司、天气一角；纯列表不可点；价格免责 hint

## 三、与 Web 版的功能差距（改版要不要补的功能位）

Web 有、小程序没有：**交通住宿票卡、景点餐厅候选、现金准备、攻略收藏、确认中心、我的/设置页（改昵称头像）、行程体检 🩺、编辑旅程（标题/日期/封面）**。
改版时建议至少预留：编辑旅程入口、我的/设置页（Web 已有昵称体系）两个功能位。

## 四、现状 UI 体检（改版切入点）

1. **app.css 重复 4 次**：894 行实为 ~223 行内容 ×4（第 1/204/418/621 行同头注释）——历次页面迁移把整文件复制叠了 4 层。改版第一刀：去重成单份 + 建立 token。
2. **零 design token**：无 `var(--x)`，全部硬编码 hex（奶油底 #fffdf8/#f7f5ef、描边 #dcded8、正文 #1e2421、绿 #37715a、蓝 #0071e3、橙 #e45f36…）。改主题=全文件替换。
3. **零全局组件**：无 components 目录，勾选框/头像/进度条/卡片全靠每个页面手拼 class；弹层全用原生 Modal/ActionSheet/Toast（系统样式，无法品牌化）。
4. **无暗色模式**：全库无 dark 适配（Web 有浅暗双色）。
5. **加载态简陋且不统一**：统一一行「加载中…」文字，无骨架屏；页面加载写法三种风格混用（useDidShow / useEffect / 渲染期直调）。
6. **地图 marker 图缺失**（上述 bug），地图页无下拉刷新、返回用 redirectTo。
7. 交互基准：7 页有下拉刷新、flywhere 显式关闭；删除类操作全走系统确认弹窗。

## 五、改版硬约束（皮可以换，这些不能破）

1. 数据层 `src/rdb/` 七件套（models.* 直连、withId 归一、写后读用 idList）——改版不碰逻辑，只动 Taro 组件与样式。
2. 日志图/封面：必须走云存储 fileID + tempUrls，禁止 base64。
3. flywhere 异步 job 轮询与 AI「只转换、客户端落库」链路是平台约束（callContainer 15s 硬超时）的产物，别「优化」掉。
4. 下拉刷新开启页：trips/trip/budget/packing/journal/handbook/members。
5. 身份即 `_openid` 行级隔离，无登录页概念（静默建档）；默认昵称「微信用户」由小程序端 ensureProfile 决定。
6. 构建链：改样式后 `build:weapp` → 上传（upload 双通道）；dist 是产物不要手改。

## 六、可参考的既有设计语言

- `DESIGN.md`（Web 版现行）：Apple 亮色风——雾灰画布、白卡 8px 圆角、碳黑文字、苹果蓝唯一交互色、980px 药丸按钮、无阴影靠表面色分层。
- 小程序现行色板实为「flywhere 暖奶油调」（paper #f3f1eb / surface #fffdf8 / ink #1e2421 / 橙 #e45f36），与 Web 的 Apple 蓝体系并存、两套不一致。
- 改版方向是「对齐 Web」还是「重新定义小程序自己的语言」，是需要先拍板的第一决策。

## 三、验收过程中发现的问题及处理

### 已修复（本轮）
1. **db.ts 重复定义导致生产启动崩溃**（deployment 7207/7209 app_crashed）
   - 复现：多轮补丁叠加后 migratePg 双定义 + return 死代码
   - 修复：从 77c0050 恢复 db.ts 后干净重放迁移改动（f021202）；提交 692746f 去重
2. **生产库缺 travel_links 表**（links 接口 500，42P01）
   - 根因：上述 return 死代码使 PG extras 迁移永不执行
   - 修复：await 顺序执行后，7207 版本已在 PG 建表；7212 部署验证 links 接口 200

### 已知非缺陷事项（不阻塞）
1. **PocketBay 闲置休眠**：平台机制，应用侧无法关闭；点「唤醒并继续」10~30 秒恢复，或本地运行 `node scripts/keepalive.mjs` 保活（已实测）
2. **AI 生成耗时 20~60 秒**：模型推理固有耗时，界面已有进度反馈（已等待 N 秒）
3. **飞哪里全国探索 10~40 秒**：多轮真实航班查询固有耗时，按钮有进度反馈

## 四、测试脚本问题记录（非应用问题，已改进方法）

1. Windows 终端 GBK 编码损坏 curl 中文 body → 改为 UTF-8 文件 `--data-binary @file`
2. confirm 对话框阻塞 → 自动 accept 或提前覆写 window.confirm
3. 按钮文案选择器（「注册并开始」vs「注册」）→ 精确匹配
4. 浏览器标签偶发重置 → 单调用内自包含「导航→操作→断言」

# 出发吧 GoTrip · 微信小程序工程

由设计稿 `E:\code\picture\gotrip-ui\` 翻译并持续迭代的可运行工程。微信开发者工具「导入项目」选本目录（测试号 appid 即可）预览。**21 个页面 / 2 个组件 / 3 个 utils**。

## 功能特性 ↔ 实现对账

| 功能 | 实现 | 说明 |
|---|---|---|
| 每日行程 | `schedule` | 按天编排；时间/地点/坐标/费用/备注齐备；点卡片菜单：上移/下移（排序）、修改备注、**移动到其他天**（跨天）；站间距离估算 |
| 出发模式 | `trip-mode` | 全屏当天视图：按天切换、逐站勾选（本地记忆）、**下一站自动高亮**、距离/车程估算、**离线手绘 SVG 路线图**（assets/trip-sketch.png）、一键复制今日路线、高德多途经点全天路线链接 |
| 旅行锦囊 | `guidebook` | 美食/贴士/语言/拍摄四类卡片；**内置 24 个目的地内容库**（含出境）；AI 定制按钮（未配置大模型时提示降级）；成员自定义卡片（本地持久化） |
| 旅行地图 | `map` | **标准/卫星双图层**切换；按天分色标记 + **按天筛选**；站点卡：高德导航跳转（wx.openLocation）、**小红书攻略搜索**（复制链接）；全程里程/车程/费用统计；成员位置共享（演示锚点，注明需后端） |
| 团队预算 | `ledger`+`settle` | 记账（分类/垫付人/分摊）、**分类统计条形图**、人均消耗、**预算进度条**、**最少转账结算引擎**（分单位守恒、支持部分人均摊 sharers） |
| 打包清单 | `packing` | 内置中国出行模板（证件/衣物/电子/洗护/药品）、勾选进度、数量+备注编辑、自定义物品（本地持久化） |
| 旅行日志 | `journal` | 按天图文手记、**多图上传（chooseMedia compressed 自动压缩）**、编辑/删除（本地持久化） |
| 攻略收藏 | `links` | 小红书/公众号链接收藏（自动识别来源）、备注标题、复制直达 |
| 飞哪儿 | `flights` | 出发地/日期/人数表单 → 低价组合（早鸟/直飞/中转，**按人数精确计价**）、目的地 4 日天气 + AI 出行建议、飞猪搜索链接 |
| 成员动态 | `messages` | 创建/记账/加入等操作动态流（按行程分组） |
| AI 助手 | `已下线` | 个人主体不可提供 AI 问答/生成（深度合成类目未开放）：页面不注册、不打包（packOptions.ignore）、TabBar 中键改为「出发」指向出发模式；规则引擎能力保留在 `utils/engine.js`，企业主体版本一键恢复 |
| 使用助手 | `helper` | 功能问答：12 组关键词匹配内置指南，未配置大模型依然可用 |
| 对外分享 | `settings`+各页 | 只读链接复制 + `onShareAppMessage` 小程序卡片转发 |
| 夜间模式 | `settings`+全局 | 跟随系统（`darkmode:true`+`theme.json`+媒体查询令牌）/ 强制浅色 / 深色，**本地记忆**，页面根节点 `{{themeClass}}` 手动覆盖 |
| 天气速览 | `overview` | 行程日期窗口逐日天气+提示（引擎确定性生成，接天气 API 即换） |

## 架构

```
app.json（21页 + darkmode/theme.json）  app.wxss（设计令牌+组件库+动效系统+夜间令牌）
utils/
  data.js    共享 mock 数据（trip/stops坐标/账单/动态）—— 接后端即数据字典
  engine.js  规则引擎：最少转账(分为守恒)/天气/机票/锦囊库(24城)/攻略解析/行程生成/使用问答
  theme.js   夜间模式：auto|light|dark + 本地记忆 + 状态栏前景色
components/nav-bar（float 去表头模式/photo 白字/胶囊真实定位）
custom-tab-bar（悬浮毛玻璃胶囊：首页 / AI规划黄钮 / 我的）
pages/ …（21 页，全部 hover-class 按压反馈 + anim-rise 入场 + 暗色适配）
```

1. **去表头**：子页导航改 `float` 模式（无标题行、悬浮返回键，布局零位移）；顺带修复胶囊 `top` 用页面绝对坐标的定位 bug

3. **两个引擎级 bug 修复**：分摊取整误差（改分运算+余数记垫付人）、部分人均摊（`sharers` 字段，陈晨没吃场景）
